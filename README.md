# SQLAlchemy

Проект для работы с базой данных SQLite через SQLAlchemy ORM. Данные загружаются из [DummyJSON](https://dummyjson.com/) и сохраняются в базу со связями между таблицами.

## Описание

Реализованы:
- Подключение к базе данных
- Базовые классы таблиц (Category, Brand, Product) с Foreign Key между ними
- Заполнение таблиц данными из DummyJSON (синхронная, асинхронная и многопоточная загрузка)
- Получение данных из базы и вывод на экран
- DTO (Data Transfer Object) для удобной передачи данных
